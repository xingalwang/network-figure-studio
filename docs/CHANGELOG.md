# 更新记录

## 0.2.0

- 计算合同、依赖传播与具体内置规则分层，新增可信构建期`computations`注册；命令、参数编辑、诊断与导出显式使用同一注册表。
- 增加LeakyReLU最小算子示例；空表和不匹配规则版本明确报告不可用，不套用当前内置规则。
- 新增v3工程格式：计算与图稿独立身份、同一计算的多个表示、手工/派生注解来源、概括/详图关系及绘图组核心API。
- 增加独立标注、新增表示和所选表示的显示几何编辑；真实张量尺寸与图稿宽高、厚度和投影角度分别维护。
- v1/v2继续读取编辑，新建默认v2；使用新版图稿功能时确认创建v3副本，保留原工程、样式、路径、隐藏和手工布局。
- 参数/标签与图稿编辑动作按职责拆分；结构更新同步必要端口，保留表示几何与说明连接。
- 增强依赖方向、SDK和组合根检查，补齐扩展与兼容样例、针对性测试和开发文档。概括/详图、模块封装及自由成组尚无完整界面。

## 0.1.1

- 明确编辑器状态与动作接口，由协调器统一处理工作区切换、运算创建与图稿恢复。
- 提取共享参数草稿模型，统一基线、冲突与应用后的清理行为。
- 增加格式、模块依赖边界及统一开发检查入口，扩充贡献和扩展说明。
- 修复取消张量命令或v1升级后仍切换模式／工作区的顺序问题。
- 应用版本显示统一来自package.json；保留0.1功能范围和既有工程格式。

## 0.1.0

- 生成与绘图共用可编辑工程，支持独立布局、撤销重做、自动保存和工程文件往返。
- 浅色／深色工作站、分组命令、结构导航、属性表与计算摘要。
- 2D／3D数据、卷积、池化、ReLU、最近邻上采样、Concat和严格Add。
- 静态尺寸推导、参数量与冲突诊断；图稿更新保留手工表现。
- 矢量编辑、连接和标注、SVG／PNG导出，以及构建期插件接口。
